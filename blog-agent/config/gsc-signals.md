## The one rule this file exists to enforce

**Double down on what ranks. Stop spreading thin.** Two topics are carrying the entire
non-brand search footprint. The job is to feed that winner, not to chase new unproven clusters.

## Proven demand (rank hard here)

- **Manufacturing / Computer-Vision cluster = 100% of non-brand impressions.**
  Just **two** published posts generate all non-brand search visibility. The topic is
  validated by real impressions; the site is simply **under-supplying it**. Every new
  Cluster-A (manufacturing computer vision) post compounds a proven demand curve.
- **FMCG computer-vision quality control = the single highest-visibility page (~60% of all
  visibility).** It sits on **page 2** and converts nothing — a page-2, high-impression,
  low-CTR page is the textbook highest-ROI SEO target: a title/meta rewrite + depth pass
  moves it to page 1 without earning a single new backlink.

## Real buyer search language (use these, they have live demand)

FMCG / packaging-line inspection buyers do not search "AI-driven quality control." They search
the **defect and the line**:

- seal / sachet integrity inspection, unsealed sachet detection
- fill-level inspection, underfill detection
- cap / closure inspection (missing cap detection)
- date-code / batch-code OCR verification, print inspection
- label presence + alignment / mislabel detection
- multi-SKU changeover inspection, line-speed visual inspection (CPM/PPM)

Competitors already ranking this space (Optomech, Indus Vision, iFactory, Binary Semantics,
ImageVision.ai) lead with the **defect + throughput number**, not the buzzword. Match that.

## What every agent should do with this

1. **Prioritise Cluster A (manufacturing computer vision), especially FMCG line inspection.**
   When choosing between a proven-cluster topic and a novel one, pick the proven cluster until
   it is saturated (10+ deep posts).
2. **Write to the defect-level long-tail above**, not the generic phrase. One named defect +
   one throughput number per title beats "AI quality control."
3. **Interlink the cluster into a hub-and-spoke.** Every new FMCG/CV post links up to the FMCG
   pillar and sideways to a sibling defect post. A page-2 page rises fastest when a cluster of
   internal links points at it.
4. **Do not open a brand-new cluster** (new industry, new geography) until the proven cluster is
   supplied. Breadth is what got the site stuck on page 2 with one strong page.
