# Marketing Agent Swarm Demo — Voiceover Script

Voice direction: confident, dry, minimal. Long pauses are fine — let the screen do the talking. Never explain the mechanism. Never name a tool, model, or framework.

---

"Nobody on our team wrote this."

"This is the queue. Every card here is a finished article — researched, written, ready to go. All of it, before breakfast."

**WHAT'S HAPPENING**

"Open one. Watch it move on its own."

"One click. That's the only part a human does."

"Before it writes a single word, it goes and listens — every platform your customers actually talk on. Then it shows you what it found, and asks permission."

"Then it writes. Fact-checks itself. Builds the SEO nobody remembers to build. Proofreads its own work."

**HOW IS THIS HAPPENING**

"What you didn't see: the drafts it threw out. The angles it argued over. The version that lost."

"This isn't a mockup."

"It's already live. Already linked into the site. Already working — and while you finish this sentence, it's already started the next one."

"Done doing it manually?"

---

### Notes
- Deliberately withholds: model/vendor names, orchestration framework, agent count, exact runtime, and anything else that would let someone rebuild the pipeline from the video alone.
- The two on-screen cards ("What's Happening" / "How Is This Happening") double as the only structural labels — everything else stays unexplained by design.
- Closing line reuses the site's own CTA copy ("Done doing it manually?") so the video and the landing page feel like one thought.
